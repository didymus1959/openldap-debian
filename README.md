# OpenLDAP-Server unter Debian 12 und 13

## Projektbeschreibung

Dieses Projekt dokumentiert die Installation, Konfiguration und Administration eines OpenLDAP-Servers unter Debian GNU/Linux.

Die Dokumentation wird mit Markdown im Pulsar Editor erstellt und mit Git versioniert. Nach Abschluss wird das Projekt auf GitHub veröffentlicht.

## Unterstützte Betriebssysteme

- Debian 12 (Bookworm)
- Debian 13 (Trixie)

## Inhalte

1. Voraussetzungen und Vorbereitung
2. Installation von OpenLDAP
3. Grundkonfiguration des LDAP-Servers
4. Verwaltung von Benutzern und Gruppen
5. TLS-Verschlüsselung und Sicherheit
6. Funktionstests und Fehlersuche

## Verwendete Werkzeuge

- Pulsar Editor
- Markdown
- Git
- OpenLDAP (`slapd`)
- LDAP Utilities (`ldap-utils`)

## Dokumentation

Die einzelnen Anleitungen befinden sich im Verzeichnis `docs/`.

## Hinweise
